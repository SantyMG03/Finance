# Personal Finance & Portfolio API

> **Work In Progress**: This project is currently under active development.

A robust RESTful API built with **Spring Boot** to manage personal finances, track bank accounts, categorize daily expenses, and analyze investment portfolios in real-time.

## 🛠️ Tech Stack
* **Java**
* **Spring Boot**
* **Spring Data JPA / Hibernate**
* **Lombok**
* **Spring Validation**

## Current Status
* ✅ **Phase 1:** Core architecture and CRUD operations.
* ✅ **Phase 2:** Transactional consistency, data validation, and global exception handling.
* 🔄 **Phase 3:** (In Progress) Integrating external financial APIs for real-time market data.
* ⏳ **Phase 4:** (Planned) JWT Security and multi-user support.
